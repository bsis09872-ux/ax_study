# Chapter 01-3 용어 정리

## 1. RAG 처리 관련 용어

| 용어 | 쉽게 말하면 | RAG에서는 |
|---|---|---|
| **토큰 분할**<br>(Token Splitting) | 글을 **토큰 단위로 자르는 것**. 토큰은 모델이 읽는 최소 단위로, 단어 하나일 수도 있고 단어 조각일 수도 있음 | 긴 문서를 "500토큰씩" 같은 기준으로 잘라 청크를 만듦 |
| **임베딩**<br>(Embedding) | 글을 **숫자 목록(벡터)으로 바꾸는 것**. 뜻이 비슷한 글은 비슷한 숫자가 나옴 | 질문과 문서를 벡터로 바꿔서 의미가 가까운 문서를 찾음 ⭐ 검색 단계의 핵심 |
| **파인튜닝**<br>(Fine-Tuning) | 이미 학습된 모델을 내 데이터로 **한 번 더 공부시키는 것**. 모델 자체가 바뀜 | RAG와 비교되는 방법. RAG는 모델은 그대로 두고 **참고자료를 옆에 붙여주는** 방식 |
| **캐싱**<br>(Caching) | 한 번 계산한 결과를 **저장해 두고 재사용하는 것** | 같은 문장을 매번 임베딩하거나 같은 질문에 매번 LLM을 호출하지 않아서 돈과 시간이 절약됨 |

> 💡 "텍스트를 벡터로 바꾸는 과정은?" → **임베딩**

## 2. 유사도 / 거리 측정 방법

| 용어 | 쉽게 말하면 | 예시 / 특징 |
|---|---|---|
| **코사인 유사도**<br>(Cosine Similarity) | 두 벡터가 **같은 방향을 가리키는지** 봄. 길이는 무시하고 방향만 봄 | 값의 범위는 -1 ~ 1이고, **1에 가까울수록 비슷함** ⭐ 임베딩 검색에서 가장 많이 씀 |
| **해밍 거리**<br>(Hamming Distance) | 길이가 같은 두 문자열에서 **다른 자리가 몇 개인지** 셈 | `1011` vs `1001` → 1자리만 달라서 거리 = 1 |
| **피어슨 상관계수**<br>(Pearson Correlation) | 두 값이 **같이 오르내리는지**(선형 관계) 봄 | 키가 크면 몸무게도 큰지 보는 식의 통계 지표. 범위는 -1 ~ 1 |
| **자카드 유사도**<br>(Jaccard Similarity) | 두 집합이 **얼마나 겹치는지** 봄<br>= 교집합 ÷ 합집합 | {사과, 배} vs {사과, 귤} → 1/3 ≈ 0.33. 벡터가 아니라 **단어 집합**으로 비교 |

> 💡 "임베딩 벡터끼리 의미 유사도를 잴 때 대표적인 방법은?" → **코사인 유사도**

### 코사인 유사도 한눈에 보기

```
같은 방향 →  →     : 1    (매우 비슷)
직각      →  ↑     : 0    (관련 없음)
반대 방향 →  ←     : -1   (정반대)
```
